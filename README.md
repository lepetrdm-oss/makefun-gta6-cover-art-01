An offline web app that turns any photo and a caption into poster-style cover art — the multi-panel look with bold lettering and a sunset or neon colour grade — exported as a PNG to share.

Pick a layout (one photo, hero + two, three panels, or a four-panel grid), drop your own photos into the panels or use the built-in samples, drag to crop and position each photo, edit the title and subtitle, choose a colour grade, and export in 1080 × 1080, 1080 × 1350 or 1920 × 1080. Everything runs locally in the browser: no network request, no upload, no account. The display fonts (Anton and Bebas Neue, both SIL Open Font License) ship under `app/fonts/`.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
